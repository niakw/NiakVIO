OFFICIAL BRAND REFERENCES / TRADEMARK NOTE
==========================================

The pack differentiates between brand marks and NiakVIO generic technical badges.

Verified official reference pages consulted for the brand systems:
- Dolby Atmos / Dolby Vision: official Dolby Newsroom media kits and Dolby brand guidelines.
- DTS:X / DTS-HD / DTS-HD Master Audio: official DTS/Xperi product/patent pages.
- IMAX / IMAX Enhanced: official IMAX brand site / IMAX consumer pages.
- Blu-ray Disc / Ultra HD Blu-ray: Blu-ray Disc Association Licensing Office.

Important legal/use note:
Official brand logos can be protected trademarks and some marks (notably Blu-ray / Ultra HD Blu-ray) are subject to logo-license rules for certain commercial uses. This ZIP is an engineering/UI asset pack; inclusion does not itself grant a trademark/logo license.

Asset provenance in badge_catalog_v2_complete.json:
- official_reference_retrieved: a reference asset retrieved from an official/brand context during this work.
- user_supplied_brand_or_technical_asset: supplied in the original Elite-Badges ZIP and normalized here.
- niakvio_generated_generic: original NiakVIO UI label generated for a technical concept; not presented as an official certification logo.

4K / 2160p note:
4K/2160p is treated as a generic resolution label unless a separate, confirmed Ultra HD Blu-ray source is present. It is never used to imply Blu-ray certification/source.
