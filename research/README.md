# International provider discovery research

The files in this directory are generated by the manual `MANUAL - International Provider Discovery` workflow.

- `international-provider-candidates.xlsx`: human-readable candidate catalogue with country coverage and NiakVIO hub gaps.
- `international-provider-candidates.json`: structured source for review and downstream tooling.
- `international-provider-candidates.csv`: flat export.

Rules:
- candidate `route`/`hub` values must be actual web, status/domain-hub, Telegram/Telegraph or equivalent address-source endpoints;
- repository URLs are research evidence only and are forbidden as candidate routes/hubs;
- selection is country/market coverage-first, capped at 100 candidates;
- the workflow is manual-only and never mutates provider code, manifests, or `provider-hubs.json` automatically.
